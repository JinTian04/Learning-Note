### 3. 分辨率也参与本轮高斯增长率计算

`F:\Learning Things\Fastergs改进版\3DGS_2607_dense_up\utils\schedule_utils.py:91`

```python
next_n_gaussian = int(
    (self.max_n_gaussian - self.init_n_gaussian)
    / cur_scale ** (2 - iteration / self.densify_until_iter)
) + self.init_n_gaussian

adjusted_max_rate = (
    self.max_densify_rate_per_step
    * cur_scale
    / self.max_reso_scale
)

return min(
    max((next_n_gaussian - cur_n_gaussian) / cur_n_gaussian, 0.),
    adjusted_max_rate,
)
```

注意：`cur_scale=4` 表示宽高都缩小到四分之一，像素数约为全分辨率的 `1/16`。代码中的最终 rate 同时受“目标数量差距”和“单轮上限”约束。
