# 两张图像如何从 2D-2D 匹配恢复相对位姿并三角化初始 3D 点？

## Codex 教学内容

### 1. 内参逆变换得到什么

像素齐次坐标 `p = [u, v, 1]^T` 经过 `x = K^-1 p` 后，得到的是相机坐标系中的归一化成像坐标，也可以理解为从光心出发的一个方向。所有 `λx（λ > 0）` 都投影到同一个像素，所以单个像素只确定一条射线，不能确定深度 `λ`。

更严谨地说，`K^-1 p` 给出射线方向；光心和相机位姿共同把它变成世界坐标系中的完整射线。

### 2. 为什么需要本质矩阵

两张图中的射线目前分别写在两个相机坐标系里。要三角化，必须先知道相机 2 相对于相机 1 的旋转 `R` 和平移方向 `t`。

对于一个真实匹配点，两条观察射线与两个相机光心之间的基线必须位于同一个平面，这就是极线几何的共面约束。对已经去除内参影响的归一化坐标 `x1、x2`：

`x2^T E x1 = 0`

其中：

`E = [t]× R`

`R` 表示相机之间的相对旋转，`[t]×` 表示用平移向量与另一个向量做叉乘。因而本质矩阵不是直接储存 3D 点，也不是输入一个匹配点就输出位姿；它把相对旋转和平移方向压缩成一个约束，使许多正确匹配必须同时满足这个约束。

COLMAP 使用多对匹配并结合 RANSAC 排除错误匹配，估计 `E`；再分解 `E` 得到候选的 `R、t`。分解会产生多个候选，选择能让三角化点同时位于两台相机前方的那个解。这里恢复的 `t` 只有方向，没有长度。

### 3. 如何三角化以及为什么没有尺度

可以把第一台相机设为世界原点，投影矩阵写作 `P1 = [I | 0]`，第二台写作 `P2 = [R | t]`。然后寻找一个 3D 点 `X`，使它投影到两张图时尽量接近观测到的两个像素。

理想情况下，两条反投影射线相交于 `X`；实际中受像素定位误差、镜头模型误差和错误匹配影响，它们常常不严格相交，所以三角化实际解的是一个最小误差问题，而不是机械地取精确交点。

如果把所有 3D 点和所有相机平移同时放大 `s` 倍，它们在图像中的投影不变。因此图像只能恢复场景形状、相机旋转和平移的相对比例，不能决定一米到底有多长。已知相机基线、已知物体尺寸、GPS 或其他尺度传感器才能提供米制尺度。

### 4. 多对匹配增加了什么

把 `E` 展开为 9 个数字 `e11 ... e33`。每一对已知的 `x1、x2` 代入 `x2T E x1 = 0` 后，只得到一个关于这 9 个未知数的标量方程。因此三对匹配只有三个方程，不能确定一般的 `3×3` 矩阵。

不过 `E` 不是任意矩阵：整体乘一个非零尺度不改变约束，而且它必须具有本质矩阵特有的结构。若只把它当作“差一个整体尺度的矩阵”线性求解，经典八点法使用至少 8 对匹配；若利用 `E = [t]×R` 的结构——旋转 3 个自由度、平移方向 2 个自由度，共 5 个自由度——校准相机可用五点法产生候选解。

真实像素存在定位噪声，所有方程通常无法同时精确等于零。超过最少数量的正确匹配会形成冗余约束，使算法能寻找“总体上最符合这些匹配”的 `E`，降低少数像素误差对结果的影响。

错误匹配不服从同一个极线几何。RANSAC 会反复抽取最小匹配子集来生成候选 `E`，再用其余匹配检查候选：极线误差足够小的记作内点。获得最多一致内点的模型胜出，并通常使用这些内点重新估计。若错误匹配过多、呈系统性一致，或场景退化，仍可能估计失败或得到错误模型。三角化通常发生在这次几何验证之后。

> 像素经过内参逆变换以后，会得到一条射线，我们目前已经有了一对匹配点，也就是有了两条射线，然后我们要确定的是两条射线之间的交点，我们认为交点就是我们三角化成功的点，但是问题是，由于我们是在图像特征点进行的匹配，一个是有像素误差，另一个是匹配过程也存在误差，所以导致射线不会严格相交，所以我们就采用了射线之间的最短距离的点或者中点作为三角化成功的点，然后把这些点根据相机模型和内参重新投影会图片上，根据重投影的误差来判断这个点是不是可能为三角化成功的点，于此同时，我们需要计算这个点实际在空间中的位置坐标，于是我们需要一些几何上的计算方法，这个时候就引入了本质矩阵，本质矩阵的假设是建立在2d-2d之间的匹配，由相机基线，通过光心的两条射线构成了一个极平面，我们根据这个三角形关系来计算实际空间中点的位置坐标，实际上我们要构建方程，这个方程就是\(x_2^TEx_1=0\)，它的意思需要拆开来解释，首先需要明白E=t叉乘R，这个R就是一条射线旋转到另一条射线位置产生的旋转，t就是相机基线的方向，二者相乘，就构建出了一个垂直于极平面的平面，所有两条射线所在的平面和这个E的平面垂直，得到了方程的0的关系，但是E是一个9个分量的矩阵，如果要解这个方程，我们有两种方法，一种是求解8个方程，另外一种是求解5个分量，3个旋转，2个平移，这里又涉及到一个E的特性，由于E是由叉乘求解出来的，因此它天然就少一个维度，因为我们求解的两个模式都少了一个分量，最后得出来的E也只是一个比例关系，是一个平面，这里需要注意的是，我们在求解方程之前会经过一个RANSAC处理错误匹配的过程，因为要求解8个方程才能得到一个满足的E，如果有错误匹配的话会严重影响其它正确匹配的三角化结果，在求解得到E以后，我们还有新的问题，就是这个E它是一个平面，正负都可以，这样就导致，分解出的R和t可以有两种符号，一共四种组合，而本身极线约束解决不了这个和他不在一个平面内的E的问题，因此，我们需要用三角化的点是否大多数都在相机的正深度位置这个事项，来判断R和t的符号，求解出来以后，我们还需要考虑，两条射线的夹角是否太小？导致三角化出现的点在特别远处，需要过滤这种情况，此外是，因为两个相机之间的基线我们没有真实的距离，因此我们求出来三维空间的点也没有真实的尺度

> 我现在有一点不明白\(x_2^TEx_1\)=0中，什么是未知数？

Codex 判断：需要按阶段区分同一公式的用途。估计本质矩阵时，`x1、x2` 是已经匹配并经过内参归一化的已知观测，未知数是 `E` 的矩阵元素／5个本质自由度；每对匹配提供一个标量约束。RANSAC 评分候选时，`x1、x2、E` 都已知，公式用于计算接近零的残差，不是在解新的未知数。三角化的3D点或射线深度属于之后的另一组方程，不是此公式中的未知量。

展开后，若 `x1=[u1,v1,1]^T`、`x2=[u2,v2,1]^T`，一对匹配给出：

`u2*u1*e11 + u2*v1*e12 + u2*e13 + v2*u1*e21 + v2*v1*e22 + v2*e23 + u1*e31 + v1*e32 + e33 = 0`。

其中所有由 `u1,v1,u2,v2` 组成的系数均已知，`e11...e33` 是估计阶段的未知数；整体尺度和本质结构会进一步减少独立自由度。

教学后的回答：

> RANSAC抽取少量匹配、生成候选模型的时候，x1,x2已知，E未知，求E，E就是候选模型，当用候选E检查其余匹配的时候，不在求未知数了，而在求方程的解是否真的趋近于0

Codex 判断：正确区分两个阶段。措辞修正：评分阶段不是再次“求方程的解”，而是将已知的 `x1、x2、E` 代入并计算极线残差，检查其是否足够接近零。

RANSAC 循环的闭卷回答：

> 因为一个错误匹配就可以很大程度影响三角化，所以要重复抽样，选择最合适的一组结果，利用方程验证候选E，\(x_2^TEx_1\)是否等于0，选出最佳候选以后，可能这个候选计算的时候有被错误匹配干扰过，所以在用所有内点优化一次

Codex 判断：已经理解重复随机抽样、候选估计、全体评分、选择最佳模型和内点重估的主循环。两处修正：评分使用极线残差小于阈值而非严格等于零，因为正确匹配也有测量噪声；用全部内点重估的主要原因是最小样本太少且受噪声影响，用更多一致观测降低估计方差，而不是默认最佳样本仍含错误匹配。

RANSAC 细节修正回答：

> 因为即使是正确的匹配，也会有像素级别的误差，也就是投影还是会有误差的，因此要求残差小于某个阈值
> 因为即使是正确匹配估计，也会存在误差，500个内点带来的约束要比5对正确匹配更多

Codex 判断：正确。已经理解残差阈值用于容纳测量噪声，使用全部内点重估通过更多一致约束降低估计误差。RANSAC 局部环节通过。

四组候选来源的复核回答：

> 因为U的三个方向分量，有一个因为sigma的分量为0，导致和U相乘，U的一个分量始终为0，也就是t，我们不知道它的方向，对于R来说，R是一个旋转矩阵，\(W,W^T\)表示的是旋转方向90°和负90°，正深度检查就是为了筛选出正确的方向，保证大多数点在相机的正深度位置

Codex 判断：核心正确。精确修正：`u3` 本身不是零，而是 `Σ` 中与其对应的系数为零，因此 `E` 的输出缺失 `u3` 方向；该缺失方向是输出平面的法向，所以 `u3 = ±t`。`W/W^T` 提供正负90°辅助旋转并构造 `R1/R2`，与 `±t` 组合为四组；正深度筛选的解释正确。
