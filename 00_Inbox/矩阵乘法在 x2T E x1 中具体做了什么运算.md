## 当前关键澄清

采用 `X2 = R X1 + t` 的坐标约定：

- `R x1`：只把相机 1 的观察方向旋转到相机 2 坐标系。
- `t`：在相机 2 坐标系中连接两个光心的基线方向（符号取决于坐标约定，但不影响此处几何关系）。
- `[t]× v = t × v`：不是给 `v` 加上平移，而是与 `v` 做叉乘。
- `t × (R x1)`：得到同时垂直于基线 `t` 和旋转后射线方向 `R x1` 的向量，因此它是极平面的法向量 `n`。
- 归一化图像点 `x2 = [u,v,1]^T` 同时也表示相机 2 的射线方向。它在极平面内当且仅当 `n^T x2 = 0`。
- 当归一化图像平面取 `z=1` 时，平面方程 `n^T x=0` 限制到图像平面，就成为二维直线方程 `a u + b v + c = 0`。因此同一个三维法向量 `n=[a,b,c]^T` 也可作为二维极线的齐次系数。

## Codex 教学内容

设 `x1 = [x, y, 1]^T`，`E` 第一行为 `[e11, e12, e13]`，那么 `E x1` 的第一个数字不是笼统的“第一行乘第一列”，而是：

`e11*x + e12*y + e13*1`。

`E` 的三行各做一次同样的乘加，得到 `l2 = E x1 = [a, b, c]^T`。这三个结果不再表示一个图像点，而是第二张图中直线 `a*u + b*v + c = 0` 的三个系数。

第二张图的匹配点仍按统一约定写成列向量 `x2 = [u, v, 1]^T`。要把它代入上面的直线方程，需要计算 `u*a + v*b + 1*c`。把同一个运算写成矩阵形式就是：

`x2^T l2 = [u, v, 1] [a, b, c]^T = a*u + b*v + c`。

因此 `T` 不是为了随意制造一个数字，而是把点的列向量横过来，使这个乘法表达的正好是“将点代入直线方程”。结果为零表示点在线上；不为零表示点偏离这条线。

## 最终闭卷解释

> 因为普通位姿变换矩阵是这样的，Rx+t，但这里是叉乘，对X1进行R的旋转，确实会让x1变成第二个相机的朝向，t表示的是两个相机的连线，因此，进行叉乘的话，会计算出极平面的法线，然后我们把x2的数据带进去，相当于是垂直向量相乘，所以得到了结果为0 我是这么理解的

Codex 勘误：这里的“让 `x1` 变成第二个相机的朝向”应理解为“将同一观察方向改用相机 2 坐标系表达”，不是改变相机 2 自身的朝向。
